Give each Collection an icon of its own, so editors find one at a glance.

Every Collection in the sidebar used to be drawn by the same mark, and nothing let you change it. A Collection's settings and Create Collection now open with an Icon field, with 63 icons to pick from in groups, from Pages and posts to Marks and signs.

- **You find an icon by what it shows**, not by the name the icon set gives it: each one carries the everyday word for what it draws, such as Car, Location or Graduation cap. The filter in the picker matches a group's name too, so "vehicle" reaches the Car.
- **The icon stands wherever the Collection appears**: beside its name in the sidebar, in the rows of an Entry field that points at that Collection, and in the dialog that asks for a Value such a field needs. An icon you save shows at once, with nothing reloaded.
- **A new Collection starts with the Layers mark**, which is what every Collection was drawn by before, so a Collection nobody gives an icon looks as it did.
- **The icon stays decoration.** A screen reader reads a Collection's name and how many Entries it holds, as before, and never the drawing beside them. In the picker each choice is read out as its own word, and the one that is chosen is marked with a check rather than by its highlight alone.

A Collection that was given another Lucide name through elek.io Core keeps it. The picker shows that name as it is stored and saves it again untouched, and the Collection is drawn by the Layers mark where elek.io Desktop has no drawing of its own for it.

Nothing about your Projects changes, and nothing needs a migration.
